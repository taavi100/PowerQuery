# PowerQuery





See teeb rakendusega samasse kausta Tabel.txt faili kus on PowerBi Enter Data tabeli andmed.

Kui tavaliselt on Enter tabeli ridade arv piiratud 3000 reaga aga rakendusega genereeritud skripti ridade arv ei ole piiratud, saab põhimõtteliselt teha suvalise pikkusega Enter tabeleid.

Andmed loetakse sisse parameetriga ette antud xlsx tüüpi failist





Programmi käivitamise näide

```console

PowerQuery "C:\Users\Username\Documents\Test.xslx"

```
